# jack meme

A meme website: full-screen picture of jack with a fart noise looping forever.

## Run locally
```
npm start
```
Then open http://localhost:3000

## Deploy on Railway
1. Push this repo to GitHub.
2. In Railway: **New Project → Deploy from GitHub repo** → pick this repo.
3. Railway auto-detects Node, runs `npm start`, and serves on its `$PORT`.
